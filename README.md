# 轻松刷真题 · MVP

Vue 3 + uni-app，面向 HBuilderX 和 Android 手机、平板。奶油色背景、草绿色、大圆角、扁平界面。

## 当前功能

- 选择级别、年份、试卷、题型后直接做题。
- 选词填空直接点击原文空位弹出词库，选择后在原文显示字母和单词，可再次点击修改；不再显示独立答题区。
- 长篇阅读、仔细阅读以原文为主，点击悬浮“答题”查看全部题目，点击题目向下展开选项。已答题直接显示“已选字母”和选项内容；填空词库同样使用顶部下拉窗口。
- 写作、翻译保留输入区域。
- 听力按原卷新闻、对话和篇章分组，同组题目在一页滚动阅读；上一题、下一题按组切换，播放不中断。
- 每次选择、输入、切换题目时同步保存到本机；重开恢复答案和题目位置。
- 首页继续上次、答题卡跳转、三档阅读字号。
- 首页“历史”自动汇总做过的试卷，可继续作答或整卷评分；兼容已有的本机作答进度。
- 练习页“评分”、选题页“整卷评分”和历史页均可随时评分；无需做完整卷，空题计 0 分。
- 按官方题型权重计算练习估分，作文、翻译未作答为 0 分，已作答支持 0–15 分自评；缺少原题、已答题的答案或主观题自评分时保留待评，不冒充判错。每次评分独立保存作答快照，可查看旧评分。
- 当前题型结束后点击“下一题”进入同套下一可用题型，恢复该题型已有进度；缺失题型自动跳过，最后一个题型显示练习保存结果。
- 长篇阅读、仔细阅读页面底部的“上一题／下一题”直接切换上一／下一可用题型，保留进度，不自动弹出小题。小题通过悬浮“答题”手动选择，窗口顶部只保留关闭按钮。
- 其他题型的“上一题”返回上一小题或听力组；当前题型第一题可回到上一可用题型末题，并保留作答。
- 点击“查看答案与解析”核对客观题答案和已有解析，显示当前作答是否正确；切题后重新隐藏。写作、翻译通过“查看答案”展示已有内容，不自动判分。
- 阅读原文使用宽屏单栏，手机整页滚动；写作、翻译在平板分栏，手机上下排列。
- 听力音频离线播放、暂停、拖动进度和断点续听；切换题目持续播放，离开页面或切到后台暂停。

已内置 `解析结果/` 中的 **119 套真题：四级 64 套、六级 55 套**。全部通过现有 Pydantic 模型校验，保留题号、文字与选项顺序。没有外部题库导入入口。

原题存在缺项：33 套缺听力、3 套缺整部分阅读、1 套缺写作，涉及 34 套试卷。缺失题型保留入口并标注“题目缺失”，用户点击后提示具体缺项，留在选题页；同套其他题型仍可正常练习。直接打开缺失题型也会提示，不生成空练习或覆盖已有进度。

已接入同目录下已生成的 `答案.json`，按级别、年月、套号和题号匹配。答案有冲突、重复、题型不符、字母超出原题选项的条目不参与判定；缺少答案、写作或翻译内容时统一显示“答案缺失”，缺解析显示“解析暂缺”。不补写或推测缺失内容，未新增错题本。

当前已更新 **56 份答案文件、1738 道可展示答案、1517 条解析**。其中 1458 道来自答案 PDF，140 道来自外部参考资料，140 道在源文件中标为推导答案。按用户要求，应用统一显示“答案”，不展示来源或推导标记；客观题均按现有答案对比作答。来源记录仍保存在开发报告中。仅含题号和答案字母的 Markdown 表格行不作为解析展示。

119 套试卷尚未全部具备答案；当前答案文件没有作文、翻译参考内容，仍保留相应缺失提示。导入数量、来源、排除的题号和诊断见 `work/app-library-report.json`。答案 JSON 的 `answer_text` 可能错取词库文本，应用始终以原题对应字母的选项文本展示，原始答案文件保持只读。更新内置答案不会修改已保存的作答或听力进度。

已接入全部 **22 份本地录音，覆盖 26 套真题**。17 份按明确文件名匹配，其余 5 份通过录音开头的对话、新闻及提问顺序与试题比对确认：2025 年 6 月四级、六级以及 2026 年 6 月六级均为第 1 套；六级 2022 年 6 月和 9 月各自三套的 25 道题及选项顺序完全一致，分别共用同场音频。带时间戳的核对证据、音频摘要和题序摘要保存在 `scripts/audio_verified_mappings.json`，汇总见 `work/app-audio-report.json`。

未找到本套音频时仍显示“暂无听力音频”。原题缺失但音频明确对应本套时，可在缺项提示后单独播放音频，不生成题目或空的作答进度。

音频全部随应用离线打包，当前资源约 550 MiB；共用录音使用同一个资源文件。部分原文件扩展名是 MP3、实际容器为 M4A，打包副本使用实际扩展名；内容未转码、未修改原录音。不从“第3套与第1或第2套相同”等不唯一说明猜测录音对应关系，核对记录所绑定的录音或题目摘要变化时会拒绝旧匹配。

## 在 HBuilderX 中运行

1. HBuilderX → 文件 → 导入 → 从本地目录导入，选择本项目目录 `E:\CET46_practice`。
2. 首次使用在项目终端执行 `npm install`。这是 Vue 3/Vite CLI 项目，源码位于 `src/`。
3. 选择“运行到浏览器”预览，或连接 Android 手机/模拟器后选择“运行到手机或模拟器”。
4. 打包 APK 前打开 `src/manifest.json`，使用自己的 DCloud 账号生成 AppID，再配置包名、签名证书。项目未填写他人的账号、AppID 或签名。

本地浏览器预览：

```sh
npm run dev:h5
```

验证与资源编译：

```sh
npm test
npm run test:e2e
npm run build:h5
npm run build:app
```

端到端测试使用本机已安装的 Chrome，分别验证 390×844 手机和 1180×820 平板布局。截图与试跑报告写入工作区 `work/`。`build:app` 生成 `dist/build/app/` 原生 App 资源，APK 仍需 HBuilderX 打包；浏览器验证不能替代 Android 真机验证。

## 数据和进度

- `src/data/catalog.json`：内置试卷目录。
- `src/static/papers/`：随应用打包的离线题目快照，原解析文件只读。
- `src/data/audio.json`、`src/static/audio/`：听力音频目录和离线文件。
- `scripts/package_audio.py`：开发时整理并复制套号明确的音频，Pydantic 报告写入 `work/app-audio-report.json`；运行 `E:\四六级真题\.venv\Scripts\python.exe scripts\package_audio.py`。
- `scripts/package_library.py`：开发时打包当前工作区的内置题库，使用现有 Pydantic 模型验证整批后写入应用资源。运行 `E:\四六级真题\.venv\Scripts\python.exe scripts\package_library.py`；缺项及解析诊断单独写入 `work/app-library-report.json`，不添加到试题正文。
- `src/utils/paper.mjs`：题型到页面的适配，保留题号、文字、选项顺序；非 `available` 内容不开放作答。
- 听力分组仅影响页面展示，仍按原题号保存；填空沿用解析结果提供的字符位置定位，避免把正文中的同号数字误作空位。
- `src/utils/solutions.mjs`：按原题字母核对答案；答案与用户作答独立，不改动已有进度格式。
- `src/utils/storage.js`：逐试卷、逐题型保存，键前缀 `cet:progress:v1:`。读取失败时不覆盖旧进度，保存失败时显示重试入口。
- `src/utils/history.mjs`：按试卷汇总作答历史；仅打开而未作答的试卷不产生练习记录，但主动评分的空卷会保留。已有作答无需迁移；新记录保留首次作答时间，之后清空答案仍可找到。
- `src/utils/scoring.mjs`：按固定的 55 道客观题和 2 道主观题计分，未答不缩小分母；评分快照按 `cet:scores:v1:<paperId>` 保存，与当前进度独立。主观题文本修改后不沿用旧自评分。
- `src/utils/listening-player.mjs`：管理播放生命周期，位置单独保存在 `cet:audio:v1:`，按音频摘要恢复，不改动作答记录。音频替换后从头开始。

开发数据路径：解析项目、Python 环境、`解析结果/` 和临时报告 `work/` 仍位于 `E:\四六级真题`；原始题库和录音仍位于 `E:\四六级题库`。应用源码、依赖和内置资源位于 `E:\CET46_practice`，应用运行不依赖外部解析目录。

不依赖后端，不上传作答。进度保存在应用本地，卸载、清除应用数据或浏览器站点存储会清除进度。未来新增已确认无误的内置真题时，保持试卷 ID、题号和题型 ID 稳定，即可沿用已有进度。

框架依据：[uni-app CLI / HBuilderX](https://uniapp.dcloud.net.cn/worktile/CLI.html)、[HTML5+ 本地文件读取](https://www.html5plus.org/doc/zh_cn/io.html)、[uni-app 音频 API](https://uniapp.dcloud.net.cn/api/media/audio-context.html)。

## 评分依据

采用 2016 年改革后的题型占比：听力 35%、阅读 35%、写作与翻译各 15%。听力 1–15 题每题占 1%，16–25 题每题占 2%；阅读选词填空每题占 0.5%，长篇阅读每题占 1%，仔细阅读每题占 2%。作文、翻译各按 0–15 分自评，未填写自评分时不擅自给分。

官方报道分还需加权、等值和常模转换，不能用本机答对数精确还原。本应用展示“练习估分”，将卷面加权分线性折算到 710 分制；听力、阅读的折算上限各为 248.5，写作、翻译各为 106.5。它们不等同于官方转换后单项的 249、249、212 分。待评部分显示可能得分上限，完整判定前不把当前已计分结果当作完整总成绩。

来源：[官方分数解释](https://cet.neea.edu.cn/xhtml1/folder/19081/5124-1.htm)、[四级笔试结构](https://www.neea.edu.cn/html1/report/16123/196-1.htm)、[六级笔试结构](https://www.neea.edu.cn/html1/report/16123/201-1.htm)、[教育部中国大学生在线的题型及评分档次说明](https://dxs.moe.gov.cn/zx/a/kskt_yy/210601/1693612.shtml)。
