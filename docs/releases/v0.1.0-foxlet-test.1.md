## 更新内容

- 保留原有 HTML5+ 页面架构和 iOS 风格，增加阅读原文点词翻译、真实系统长按选区、选择整句、译文复制和返回键关闭。
- 增加轻量加载、淡入上移、柔和弹性减速和文本切换动效，支持减少动态效果。
- 封装 `translator.init/translate/isReady/getStatus/destroy`；请求序号防止旧回包覆盖新选择，精确文本内存缓存及同请求合并。
- 集成 Foxlet v0.5.0、Kotlin Coroutines 及约 52 MB en → zh-Hans 模型；所有模型随包打入 assets，后台安全安装至私有目录并校验 SHA-256，使用官方 ExternalModel API。
- 新增可构建的普通 5+ Android 宿主、Native.js Java/Kotlin 异步桥接、资源准备脚本、APK 内容校验和真实 WebView 检查脚本。未迁移到 uni-app。
- 显式移除 SDK 依赖合入的 INTERNET 权限；翻译无需在线 API，不下载模型，不上传文章。
- 保留全部 119 套试卷、73 份独立引用音频和现有六类题型。

## 待验收与限制

- 当前自动化设备为 x86 Android 模拟器，只计入不兼容设备处理、真实桥接和 UI 验证；它会返回 `UNSUPPORTED_DEVICE`，不计入 Foxlet 推理成功。
- 完整业务 APK 的原生 ARM64 真机断网首启、连续点词、长按选文推理、选择手柄拖动、复制译文、进程重启后的模型复用及低内存处理仍需验收。
- 正式包名与正式证书覆盖升级尚未配置。当前测试版不能作为稳定版的覆盖更新。
- 一次专用测试包强制停止/重启的自动化命令被本机执行策略阻止，未计入冷启动通过；WebView 重载测试不能替代进程重启测试。

完整文件清单、许可及固定哈希、宿主依赖、JS 接口和本地构建操作见 [Foxlet 离线翻译交付记录](../foxlet-offline.md)。
