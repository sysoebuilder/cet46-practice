## 更新

1. 修复正式 APK 内试卷资源地址无法由原生文件接口解析的问题。App 按需加载随包试卷脚本，不依赖 file:// fetch 或 FileReader；119 套题库内容保持一致。
2. 配置翡翠字母 A 图标和原生启动图，加入 Motion 启动交接、加载骨架屏、失败重试及减少动态效果支持。
3. 为旧 Android WebView 提供定位和视口高度兼容写法，并约束 CSS 压缩目标，避免弹层被放到屏幕外。
4. 保留六类题型、原有题库、答案、进度及听力状态逻辑，附上宣传竖封面。
