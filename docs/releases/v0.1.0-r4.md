## 修复

- 修复只有阅读原文可翻译的问题。现在所有题型中已展示的英文原文、题干、选项、题目说明、听力引导、填空词库及回填单词、正确答案、解析和参考文本均接入点词与长按选文翻译。中文材料夹杂的英文也可查词。
- 题目和选项中的英文支持 Android WebView 的真实系统选区。点英文只查词；点选项字母或留白选择答案；点题号或箭头展开题目；填空字母用于重新选词，纠错标签用于打开解析。保留键盘 Enter/Space 和原有保存逻辑。
- 修复长译文无法滚动的问题：卡片内部滚动不再触发文章滚动关闭逻辑；正文独立滚动，关闭和复制操作固定可见。保留原有 iOS 风格圆角、阴影、轻量动效及减少动态效果支持。
- 修复清除选区后立即点新词被上一次长按抑制时间拦住的问题，并跟踪题目弹层卸载关闭翻译卡片。
- 保留 Foxlet v0.5.0、本地缓存、请求竞态保护、随包模型及完全本地的原生桥接；模型和题目数据未改动。输入区继续正常编辑。
